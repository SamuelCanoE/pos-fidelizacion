        Esta pestaña es para estudiar; no hace falta para vender. Muestra cómo guarda el programa los datos mientras usted atiende clientes en la pestaña Caja.

        Cola (FIFO)

        Fila normal: el primero que llega es el primero en salir. Ingresar y atender: O(1).

        Cola de prioridad (Min-Heap)

        Caja preferencial: el próximo siempre está en la raíz. Ingresar y atender: O(log n).

        Pila (LIFO)

        «Borrar último»: lo último que se escaneó es lo primero que se quita. O(1).

        Bag (bolsa)

        Carrito: se permiten repetidos y el orden no importa. Agregar: O(1).

        Lista doblemente enlazada

        Historial del día: agregar al final es O(1) y se recorre en ambos sentidos.

        Union-Find (base 1)

        Familias: si padre[i] = i, i es la raíz del grupo. «Misma familia» = misma raíz. O(α(n)).

        Tiempo de cada operación

        Las estructuras en memoria tardan microsegundos; PostgreSQL, milisegundos. Por eso el programa decide en memoria y guarda en la base lo permanente.

        Bitácora (logs)

        También se guarda en el archivo logs/pos-0.log.
